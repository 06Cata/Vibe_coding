NOTEBOOKLM CLI

NotebookLM CLI 來了

以前整理資料要開網頁、上傳檔案、切來切去。 現在有人做成開源工具，可以直接在 Terminal 操作。

這個工具可以做什麼？

串進 Python、建立一個 Notebook，就能丟網址、PDF、書的電子檔進去。 你可以把它想成：用指令建立一個可以提問的知識庫。

  • 建立 Notebook
  • 管理來源資料
  • 針對來源提問
  • 整理摘要與重點
GitHub 連結： https://github.com/teng-lin/notebooklm-py

安裝 NotebookLM CLI

先安裝套件，再安裝 Playwright 的 Chromium 瀏覽器。

Terminal
pip install "notebooklm-py[browser]"
playwright install chromium

登入與確認狀態

第一次使用需要登入，登入後可以用 auth check 確認是否成功。

Terminal
notebooklm login
notebooklm auth check --test --json

建立一個研究 Notebook

建立 Notebook 後，記得切換到該 notebook_id，後面新增來源和提問才會放到同一個研究裡。

Terminal
notebooklm create "我的研究"
notebooklm use <notebook_id>

新增來源並提問

你可以丟網址進去，再直接請它整理重點。

Terminal
notebooklm source add "https://en.wikipedia.org/wiki/Artificial_intelligence"
notebooklm ask "請整理這個來源的重點，條列式列出"
如果你平常會整理新聞、研究資料、會議紀錄，這個工具滿適合拿來玩看看。
