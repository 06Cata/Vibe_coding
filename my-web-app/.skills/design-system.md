# Design System SOP

視覺基準：
- 背景：`bg-gray-950`
- 主色：`orange-500`
- 卡片：深灰底 + 淺邊框
- 圓角：`rounded-2xl` / `rounded-3xl`
- 玻璃感：`backdrop-blur` + `bg-white/10`

頁面結構：
1. 頂部標題區
2. 操作區 / 表單區
3. 結果區
4. 歷史 / 延伸資訊區

元件原則：
- CTA 用橘色主按鈕
- 次要操作用深色描邊按鈕
- 卡片不要再包一層大卡片
- 表單欄位高度與間距一致
- loading / empty / error 都要有視覺狀態

互動原則：
- AI 生成中要有中間態
- 列表或訊息新增時可有輕微淡入或滑入
- hover 效果要節制，不要做過多花俏動畫

文字原則：
- 標題短、直接
- 說明文不要太長
- 優先繁體中文
- 技術錯誤訊息顯示給使用者前要轉成人話
